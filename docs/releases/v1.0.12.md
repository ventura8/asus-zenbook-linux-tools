# v1.0.12 — GNOME Shell 51 (Ubuntu 26.10) Window Swap Fix

**ASUS ZenBook Linux Tools v1.0.12** restores the GNOME Window Swap extension and
ScreenPad Shell OSD after Ubuntu 26.10 / GNOME Shell 51 OS updates.

---

## 🐞 GNOME Shell 51 compatibility

* `gnome/asus-window-swap@ventura8.github.com/metadata.json` now lists `"51"` in
  `shell-version` (kept contiguous `"45"`…`"51"`).
* GNOME Shell refuses extensions whose `shell-version` omits the running major
  when version validation is on — after the 26.10 upgrade the helper stayed
  installed but **INACTIVE**, so `MoveFocused` / `GetFocusedMonitor` /
  `ShowOsd` never exported on the session bus.
* Extension JS needed no GNOME 51 API port (no removed Clutter/St/Mutter APIs).
* Unit test `tests/unit/gnome/test_window_swap_metadata.py` gates the declared
  majors so a future Shell bump cannot ship without an explicit catalog update.

Diagnosed on a ZenBook Pro Duo (UX582HS) running Ubuntu 26.10 + GNOME Shell
51.0 (`metadata.json` omitted `"51"`, so Shell kept the extension inactive).
Full host proof of `GetFocusedMonitor` / ScreenPad `ShowOsd` after reinstall
and logout is still pending.

## 📦 Install

Ubuntu 26.04 (resolute) PPA:

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt install asus-zenbook-linux-tools
```

Package upgrades skip the interactive wizard, so they refresh the packaged
tree without copying `metadata.json` into the user extension. After
`apt`/`dpkg` upgrade (or a GitHub Release `.deb` upgrade), run
`sudo asus-zenbook-configure`, select **DESKTOP**, then **log out and back in**
once so GNOME Shell reloads `asus-window-swap@ventura8.github.com`.

On Ubuntu 26.10 (and other non-resolute releases), prefer the checksum-verified
checkout installer below or a GitHub Release `.deb` after `sha256sum -c`
against `SHA256SUMS`.

Other distributions:

```bash
TAG=v1.0.12 && cd "$(mktemp -d)" &&
  git clone --depth 1 --branch "$TAG" \
    https://github.com/ventura8/asus-zenbook-linux-tools.git &&
  cd asus-zenbook-linux-tools &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```

GitHub Release assets (`.deb`, Fedora/Rocky/openSUSE `.rpm`, Arch `.pkg.tar.zst`,
AppImage, Flatpak, classic Snap, plus `SHA256SUMS`): verify with
`grep -F 'asset' SHA256SUMS | sha256sum -c -` before installing. openSUSE RPMs:
`sudo zypper install --allow-unsigned-rpm ./asus-zenbook-linux-tools-*.rpm`
after checksum verification.
