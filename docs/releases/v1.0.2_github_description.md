# ASUS ZenBook Linux Tools v1.0.2 - Adaptive Touchpad Share Bounds

Touchpad Share no longer fires when you are not pressing the capacitive button.
Both touch-down and touch-up must stay inside the corner region, and the daemon
learns tighter bounds automatically from successful taps.

---

## 📱 Stricter Share gate

* Share triggers only when **both** touch-down and touch-up are inside the active
  corner bounds (fixes false positives from drifts that ended inside the old
  fixed 20% region).
* Multi-touch still cancels the gesture; lifecycle uses `BTN_TOUCH` only.

## 🎯 Automatic learned bounds

* Starts from conservative **8%** seed fractions; learns from accepted taps and
  persists to `/var/lib/asus-zenbook-linux-tools/touchpad-share-bounds.json`.
* After **8** samples, recomputes at the **85th percentile** and clamps between
  **3%** minimum and the seed maximum (never expands beyond the seed envelope).
* Malformed persisted state falls back to seeds; invalid `samples` lists are ignored.

## 🧩 Packaging & tests

* Bounds helpers live in `asus_touchpad_share_bounds.py`; install manifest and
  TOUCHPAD deploy copy the new module.
* Unit tests cover learning, persistence, start/end rejection, and helper return
  shape; smoke/e2e assert the file is installed.

## 📥 Installation

### Ubuntu PPA (resolute)

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

### Download install.sh and verify integrity (any supported distro)

Both files come from the same GitHub release tag; `sha256sum -c` is an integrity
check that the downloaded script matches its checksum file—not independent or
authenticated verification from a separate trusted channel.

```bash
curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.2/install.sh.sha256 \
  -o install.sh.sha256 &&
  curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.2/install.sh \
  -o install.sh &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```
