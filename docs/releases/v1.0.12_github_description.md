# ASUS ZenBook Linux Tools v1.0.12 - GNOME Shell 51 Window Swap Fix

**ASUS ZenBook Linux Tools v1.0.12** restores the GNOME Window Swap extension and
ScreenPad Shell OSD after Ubuntu 26.10 / GNOME Shell 51 OS updates.

---

## 🐞 GNOME Shell 51 compatibility

* `metadata.json` `shell-version` now includes `"51"` (contiguous `"45"`…`"51"`).
* Without that entry, Shell keeps the extension installed but inactive — no
  `MoveFocused` / `GetFocusedMonitor` / `ShowOsd` on the session bus.
* No extension.js API port required for GNOME 51.
* Unit test gates the declared Shell majors.

Diagnosed on a ZenBook Pro Duo (UX582HS) running Ubuntu 26.10 + GNOME Shell
51.0. Full host proof of `GetFocusedMonitor` / ScreenPad `ShowOsd` after
reinstall and logout is still pending.

PPA uploads target **resolute** and **stonking** (enable the stonking series on
Launchpad before the first 26.10 upload).

Package upgrades skip the configure wizard, so they do not refresh the user
copy of `metadata.json`. After upgrade, run `sudo asus-zenbook-configure`,
select **DESKTOP**, then **log out and back in** once so Shell reloads the
extension.

## 📦 Install

Ubuntu 26.04 (resolute) and Ubuntu 26.10 (stonking) PPA (after the series is
enabled and this tag’s upload has published):

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

Until the stonking pocket exists, use the checkout installer below or a GitHub
Release `.deb` on Ubuntu 26.10.

Other distributions:

```bash
TAG=v1.0.12 && cd "$(mktemp -d)" &&
  git clone --depth 1 --branch "$TAG" \
    https://github.com/ventura8/asus-zenbook-linux-tools.git &&
  cd asus-zenbook-linux-tools &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```

Release assets (`.deb`, `.rpm`, Arch, AppImage, Flatpak, Snap, `SHA256SUMS`):
`grep -F 'asset' SHA256SUMS | sha256sum -c -` before install. openSUSE:
`sudo zypper install --allow-unsigned-rpm ./asus-zenbook-linux-tools-*.rpm`
after checksum verification.
