# Release v1.0.1 — Dynamic Install Progress & Empty Selection

**ASUS ZenBook Linux Tools v1.0.1** makes installer progress match the work that will
actually run, treats an empty component selection as a successful no-op, localizes
desktop configure progress for five of six DE families, and hardens Gettext / packaging
gates in CI.

---

## 🌟 Key Features & Improvements

### 📊 Dynamic `[n/m]` install progress

- **`Choose components` is unnumbered** — the total is unknown until after the wizard.
- After selection, `_install_plan_progress_steps` / `_install_print_next_step` in
  `lib/install-shared.sh` number only remaining work: system deps (when
  `SKIP_PKG_INSTALL` is not `1`), scripts and services, and optional DESKTOP configure.
- Examples with `SKIP_PKG_INSTALL=1` (DESTDIR / PPA configure): WMI only prints
  `[1/1]`; WMI + DESKTOP prints `[1/2]` then `[2/2]`. With package install enabled,
  deps become `[1/N]`. Hardcoded `[n/4]` banners are gone.
- `_install_print_next_step` defaults unset `INSTALL_STEP_*` counters under `set -u`
  so kcov DE `configure_*` drivers that skip `install.sh` planning stay safe.

### ☑️ Empty selection is a successful no-op

- **TUI Ok with nothing checked**, `NONINTERACTIVE_CHOICE=` / whitespace, explicit token
  `none`, or text-mode `,` install nothing and exit 0 with
  `No components were selected. Nothing was installed.`
- Skips package install, shared-lib deploy, and every component. Does **not** print
  `ASUS ZenBook Linux Tools is ready to use.`
- **TUI Esc / Cancel** still aborts (`Installation cancelled by user.`, exit 1).
- **Text-mode bare Enter** and **no TTY without `NONINTERACTIVE_CHOICE`** still default
  to all recommended components. Token `none` stays literal in translations (same class
  as `all`).

### 🖥️ Localized desktop configure progress

Installer DESKTOP dispatch is still GNOME, KDE Plasma, XFCE, LXQt, Cinnamon, and MATE.
The nine always-on CI lanes stay Ubuntu 26.04, Debian trixie, Fedora 44, Rocky 10,
openSUSE Tumbleweed, Arch latest, openSUSE Leap 16.0, AlmaLinux 10, and Manjaro base.

| Desktop | DESKTOP shortcuts | Progress label |
| --- | --- | --- |
| **GNOME** | Yes | translated `Configure GNOME shortcuts for %s` |
| **KDE Plasma** | Yes | translated `Configure KDE Plasma shortcuts for %s` |
| **XFCE** | Yes | English `Configuring XFCE shortcuts for …` |
| **LXQt** | Yes | translated `Configuring LXQt Global Keys for %s...` |
| **Cinnamon** | Yes | translated `Configuring Cinnamon shortcuts for %s...` |
| **MATE** | Yes | translated `Configuring MATE shortcuts for %s...` |

Cinnamon / LXQt / MATE print via one-line helpers so nested `_asus_gettextf` quotes do
not inflate shell CCN. Gettext catalogs for all Whisper-aligned languages ship the new
progress and selection (`all` / `none`) strings.

### 🌐 Gettext PO lint & catalog quality

- Cheap-wave `step_po_lint` runs `msgfmt -c --check-format` on every repo `*.po`
  (fail closed if `msgfmt` is missing or no catalogs exist).
- Heavy-wave catalog freshness / quality gates are unchanged
  (`extract_pot.sh --check`, `seed_whisper_languages.py --check`,
  `check_catalog_quality.py`).

### 📦 Packaging / coverage hardening

- Deb package smoke removes leftover parent/artifact
  `asus-zenbook-linux-tools_*.deb` files before build and asserts exactly one matching
  package glob (avoids false failures when `1.0.0` and `1.0.1` sit side by side).
- Kcov `install_none` exercises `NONINTERACTIVE_CHOICE=none` so
  `_print_empty_install_completion` stays above the 90% shell gate.
- Arch/Manjaro CI images retry `pacman -Syu`/`-S` via `pacman-retry.sh` (DB resync
  between attempts) so rolling-mirror 404s for a superseded package do not fail
  Full-DE image builds. Arch pins `archlinux-mirrorlist` (not geo/fastly).
  Rocky/Alma kcov builds install `libcurl-devel` at the installed libcurl NEVRA
  (`el10-kcov-libcurl.sh`) so AppStream/BaseOS skew cannot pick `el10_2.4` devel.

## 📦 Installation Quick-Start

### Ubuntu PPA (resolute)

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

Apt install runs the interactive component wizard. Reconfigure with
`sudo dpkg-reconfigure asus-zenbook-linux-tools` or
`sudo asus-zenbook-configure`.

### curl | bash (any supported distro)

```bash
curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.1/install.sh.sha256 \
  -o install.sh.sha256 &&
  curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.1/install.sh \
  -o install.sh &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```

Headless `none` / empty selection examples stay in `docs/INSTRUCTIONS.md` (not in this
human one-liner).
