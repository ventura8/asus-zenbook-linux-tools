# v1.0.10 — SonarQube Zero, Safer Real E2E

**ASUS ZenBook Linux Tools v1.0.10** closes out the SonarQube Cloud cleanup —
zero open issues and no duplicated code — and fixes a real-system test driver
that could uninstall a working setup.

---

## 🧹 SonarQube Cloud: zero findings

* Arrays passed by nameref in the CI orchestration scripts are now also used
  directly (pending-lane diagnostics, explicit script arguments, an
  empty-coverage-map fail-closed check, a Python coverage success line).
* The catalog-quality checker returns one tuple shape; a logging test uses
  `mock.patch` instead of manual global save/restore.
* The hyphenated systemd entrypoints (`asus-hotkey-daemon.py`,
  `asus-touchpad-share.py`) are symlinks and are excluded from analysis, removing
  842 falsely duplicated lines.

## 🐛 Fix

* `scripts/run_real_e2e.sh` refuses to start when the host already has an
  install. Previously its EXIT cleanup ran `uninstall.sh` even when every test
  refused, tearing down the working setup.

No product runtime behaviour changes; validated on a ZenBook Pro Duo (UX582HS).

## 📦 Install

Ubuntu 26.04 (resolute):

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt install asus-zenbook-linux-tools
```

Other distributions:

```bash
TAG=v1.0.10 && cd "$(mktemp -d)" &&
  curl -fsSLO "https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/$TAG/install.sh" &&
  curl -fsSLO "https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/$TAG/install.sh.sha256" &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```
