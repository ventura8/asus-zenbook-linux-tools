# ASUS ZenBook Linux Tools v1.0.11 - Hardened Installer Output, SonarQube Zero

**ASUS ZenBook Linux Tools v1.0.11** hardens the installer component checklist
and takes SonarQube Cloud to zero issues, zero hotspots and zero duplications.

---

## 🔒 Installer checklist output hardening

* `--output` must resolve inside the system temp directory and must not be a
  symlink; anything else exits with an error instead of writing.
* The selection is written through a pinned temp-directory descriptor, opening
  every intermediate directory and the file with `O_NOFOLLOW`, so a symlink
  swapped in after validation cannot redirect the write.
* Output handling lives in `bin/asus_install_selection_output.py`.

## 🧹 SonarQube Cloud: zero

* The last two unused-local findings in the parallel CI lane collector are gone
  (it now works on the caller arrays by name).

Validated on a ZenBook Pro Duo (UX582HS).

## 📦 Install

Ubuntu 26.04 (resolute):

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt install asus-zenbook-linux-tools
```

Other distributions:

```bash
TAG=v1.0.11 && cd "$(mktemp -d)" &&
  curl -fsSLO "https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/$TAG/install.sh" &&
  curl -fsSLO "https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/$TAG/install.sh.sha256" &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```
