# ASUS ZenBook Linux Tools v1.0.3 - Multi-distro Release Packaging

Every `v*` tag now attaches native packages for Fedora, Rocky, openSUSE, and Arch
on GitHub Releases—alongside the existing Ubuntu `.deb` and PPA path—using one
shared payload stager so formats cannot drift.

---

## 📦 Shared staging

* [`packaging/stage-payload.sh`](../../packaging/stage-payload.sh) stages bin/lib/systemd,
  gettext `.mo` catalogs, and `/usr/sbin/asus-zenbook-configure` for all formats.
* [`debian/rules`](../../debian/rules) calls the same script for PPA `.deb` builds.

## 🐧 Native packages

* **RPM** for Fedora 44, Rocky 10, and openSUSE Tumbleweed (conditional deps + scriptlets).
* **Arch** PKGBUILD + pacman `.install` hooks sharing configure-common scriptlets.

## 🚀 Release automation

* Tag workflow `build-packages` matrix + multi-artifact GitHub Release upload.
* CI `package-smoke` builds all seven package targets (RPM×3, Arch, AppImage, Flatpak, Snap).

## 🧪 Portable installers (experimental)

* AppImage, Flatpak, and Snap bundles run `asus-zenbook-configure` with bundled
  payload (root still required). Native packages recommended.

---

## 📥 Installation

### Ubuntu PPA (resolute)

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

### GitHub Release packages

Download **`SHA256SUMS`** and your release asset from the
[v1.0.3 release assets](https://github.com/ventura8/asus-zenbook-linux-tools/releases/tag/v1.0.3),
then verify the downloaded asset before install:

```bash
grep -F 'your-asset-filename' SHA256SUMS | sha256sum -c -
sudo apt install ./asus-zenbook-linux-tools_*.deb          # Debian/Ubuntu (.deb from GitHub Release)
sudo dnf install ./asus-zenbook-linux-tools-*.rpm          # Fedora/Rocky
sudo zypper install --allow-unsigned-rpm ./asus-zenbook-linux-tools-*.rpm  # openSUSE
sudo pacman -U ./asus-zenbook-linux-tools-*.pkg.tar.zst   # Arch/Manjaro
sudo ./asus-zenbook-linux-tools-*-x86_64.AppImage          # AppImage
sudo flatpak install --system ./asus-zenbook-linux-tools-*.flatpak
sudo flatpak run org.github.ventura8.AsusZenBookLinuxTools
sudo snap install --dangerous ./asus-zenbook-linux-tools_*.snap
```

Portable AppImage / Flatpak / Snap installer bundles are also attached; native
packages are recommended for systemd and udev integration.

### Download install.sh and verify integrity (any supported distro)

Both files come from the same GitHub release tag; `sha256sum -c` is an integrity
check that the downloaded script matches its checksum file—not independent or
authenticated verification from a separate trusted channel.

```bash
curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.3/install.sh.sha256 \
  -o install.sh.sha256 &&
  curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.3/install.sh \
  -o install.sh &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```
