# Release v1.0.2 — Adaptive Touchpad Share Bounds

**ASUS ZenBook Linux Tools v1.0.2** fixes touchpad Share false activations by requiring
both touch-down and touch-up inside the Share corner, then learning tighter bounds
automatically from successful taps—no user calibration.

---

## 🌟 Key Features & Improvements

### 📱 Stricter Share gesture gate

- Share accepts a tap only when **both** touch-down and touch-up coordinates stay
  inside the active corner bounds (rejects start-outside/end-inside drifts that
  caused false positives away from the capacitive Share button).
- Touch lifecycle still uses **`BTN_TOUCH` only** (not `BTN_TOOL_FINGER`) and cancels
  when a second contact appears so two-finger taps cannot trigger Share.
- `asus_touchpad_share.py` preserves `curr_x`/`curr_y` on touch-down so corner
  gestures keep the last ABS position.

### 🎯 Automatic learned Share bounds

- Conservative **8%** seed fractions cap the top-left region at startup; learning
  never expands beyond that seed envelope.
- Each accepted tap records a normalized sample; after **8** samples the daemon
  recomputes bounds at the **85th percentile** and clamps between **3%** minimum and
  the seed maximum.
- Learned state persists atomically to
  `/var/lib/asus-zenbook-linux-tools/touchpad-share-bounds.json` (override path via
  `ASUS_TOUCHPAD_SHARE_BOUNDS_PATH` for tests). Malformed JSON or invalid fractions
  fall back to seeds; non-list `samples` arrays are treated as empty history.

### 🧩 Module split & install wiring

- Bounds learning, persistence, and `is_corner_gesture` live in
  [`bin/asus_touchpad_share_bounds.py`](../../bin/asus_touchpad_share_bounds.py);
  the event loop stays in [`bin/asus_touchpad_share.py`](../../bin/asus_touchpad_share.py).
- `lib/install-file-manifest.sh` and `deploy_touchpad_component` deploy and
  `chmod +x` the new module alongside the Share daemon symlink.

## 📦 Installation Quick-Start

### Ubuntu PPA (resolute)

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

Apt install runs the interactive component wizard. Reconfigure with
`sudo dpkg-reconfigure asus-zenbook-linux-tools` or
`sudo asus-zenbook-configure`.

### Download install.sh, verify checksum, and run with sudo bash (any supported distro)

```bash
curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.2/install.sh.sha256 \
  -o install.sh.sha256 &&
  curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.2/install.sh \
  -o install.sh &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```

Both files come from the same GitHub release tag; `sha256sum -c` is an integrity
check that the downloaded script matches its checksum file—not independent or
authenticated verification from a separate trusted channel.

Headless `none` / empty selection examples stay in `docs/INSTRUCTIONS.md` (not in this
human one-liner).
