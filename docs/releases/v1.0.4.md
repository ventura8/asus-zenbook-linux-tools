# Release v1.0.4 — Multi-Desktop E2E Testing & Package Teardown Hardening

**ASUS ZenBook Linux Tools v1.0.4** delivers comprehensive end-to-end test coverage
across all six supported desktop environments—GNOME, KDE Plasma, XFCE, LXQt,
Cinnamon, and MATE—verifying control center activation, display profiles, screenshot
triggers, hotkey daemons, and shortcut state restoration, alongside hardened package
teardown and exit-code propagation.

---

## 🌟 Key Features & Improvements

### 🖥️ Multi-desktop E2E test verification

- **All six supported desktop environments**: Full end-to-end test suites cover
  GNOME, KDE Plasma, XFCE, LXQt, Cinnamon, and MATE.
- **Settings & control center**: Validated native settings manager launching and
  D-Bus activation (`gnome-control-center`, `systemsettings`, `xfce4-settings-manager`,
  `lxqt-config`, `cinnamon-settings`, `mate-control-center`).
- **Display modes & shortcuts**: Verified fallback display settings commands and
  shortcut registration (`xfce4-display-settings`, `lxqt-config-monitor`,
  `mate-display-properties`, `kwriteconfig6`, `xfconf-query`, `gsettings`).
- **Screenshot tools**: Tested screenshot capture dispatch via D-Bus and CLI helpers
  (`ShowScreenshotUI`, `spectacle`, `xfce4-screenshooter`, `mate-screenshot`).
- **Shortcut backup & restoration**: Verified that pre-existing desktop keybindings
  are accurately backed up during installation and restored upon uninstallation
  across KDE, XFCE, LXQt, Cinnamon, and MATE.

### 🛡️ Packaging & teardown hardening

- **Prerm exit-status preservation**: Hardened [`debian/prerm`](../../debian/prerm)
  `_run_packaged_uninstall` to explicitly preserve non-zero return codes from
  `uninstall.sh` without clobbering by subsequent bytecode cleanup.
- **Bytecode cleanup**: Ensured share `__pycache__` directories are stripped cleanly
  so dpkg purge warnings are eliminated.
- **Deb package smoke**: Refined dpkg purge verification in [`scripts/run_deb_package_smoke.sh`](../../scripts/run_deb_package_smoke.sh)
  to ensure robust validation across clean reinstall and purge cycles.

### 🧪 Quality gates & test infrastructure

- **Isolated daemon E2E tests**: Split hotkey daemon and multi-DE tests into
  independent, single-process test methods with strict 20–30 second timeout budgets.
- **Nine distro lanes verified**: Validated against all nine always-on distro lanes
  (Ubuntu 26.04, Debian trixie, Fedora 44, Rocky 10, AlmaLinux 10, openSUSE Tumbleweed,
  openSUSE Leap 16.0, Arch Linux, and Manjaro base).
- **High code coverage**: Maintained $\ge 90\%$ line coverage across all product shell
  and Python daemons (96% total Python coverage).

## 📦 Installation Quick-Start

### Ubuntu PPA (resolute)

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

### GitHub Release packages (all supported families)

Download assets and **`SHA256SUMS`** from the
[v1.0.4 GitHub Release](https://github.com/ventura8/asus-zenbook-linux-tools/releases/tag/v1.0.4).
Verify the downloaded asset before installation:

```bash
grep -F 'your-asset-filename' SHA256SUMS | sha256sum -c -
```

| Asset | Install (after checksum verify) |
| --- | --- |
| `.deb` | `sudo apt install ./asus-zenbook-linux-tools_*.deb` |
| `.rpm` (Fedora/Rocky/Alma) | `sudo dnf install ./asus-zenbook-linux-tools-*.rpm` |
| `.rpm` (openSUSE) | `sudo zypper install --allow-unsigned-rpm ./asus-zenbook-linux-tools-*.rpm` |
| `.pkg.tar.zst` | `sudo pacman -U ./asus-zenbook-linux-tools-*.pkg.tar.zst` |
| `.AppImage` | `sudo ./asus-zenbook-linux-tools-*-x86_64.AppImage` |
| `.flatpak` | `sudo flatpak install --system ./asus-zenbook-linux-tools-*.flatpak` then |
| | `sudo flatpak run org.github.ventura8.AsusZenBookLinuxTools` |
| `.snap` | `sudo snap install --dangerous ./asus-zenbook-linux-tools_*.snap` (after checksum verify) |

Reconfigure after any native package install: `sudo asus-zenbook-configure`.

### Download install.sh, verify checksum, and run with sudo bash (any supported distro)

```bash
curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.4/install.sh.sha256 \
  -o install.sh.sha256 &&
  curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.4/install.sh \
  -o install.sh &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```

Both files come from the same GitHub release tag; `sha256sum -c` is an integrity
check that the downloaded script matches its checksum file—not independent or
authenticated verification from a separate trusted channel.
