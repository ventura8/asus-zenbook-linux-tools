# Release v1.0.8 — Security Hardening from SonarQube Analysis

**ASUS ZenBook Linux Tools v1.0.8** closes the security findings SonarQube Cloud
raised against the project, including a real path-traversal hole in the root
HD-audio helper, and tightens the supply-chain posture of the build images.

---

## 🌟 Key Features & Improvements

### 🔒 Root HD-audio helper confines its device path

- [`bin/asus_hda_verb.py`](../../bin/asus_hda_verb.py) takes the hwdep device
  path from `argv` and runs as root. `validated_device()` now resolves that path
  and requires it to stay inside `/dev/snd` (or `DEV_SND_ROOT`, which the kcov
  and unit fixtures set) **and** to name an `hwC<N>D<M>` node, so the helper can
  no longer be pointed at an arbitrary file through `..` or a symlink. A refused
  path exits 1 with a clear message instead of opening anything.
- Four new unit tests cover the accepted node, the traversal refusal, a
  non-hwdep name, and the CLI's exit status.

### 🧱 Build and CI supply-chain hygiene

- **Coverage install pinned**: the host merge job installs
  `coverage==7.16.1 --only-binary :all:` instead of an unpinned range, so no
  source build (and no setup script) runs in CI.
- **npm lifecycle scripts blocked**: `npm ci` in
  [`scripts/run-lints.sh`](../../scripts/run-lints.sh) and the global install in
  the lint image both use `--ignore-scripts`.
- **HTTPS enforced on downloads**: `curl --proto '=https' --tlsv1.2` for the
  NodeSource key, hadolint, the kcov tarballs on AlmaLinux/Rocky, and the xfconf
  tarball in `install-de-family.sh`, so a redirect cannot downgrade to plain HTTP.
- **Test stub permissions**: `tools/make_fake_loginctl.py` writes the stub
  owner-only (`0o700`) rather than world-readable/executable.

### 🔬 SonarQube project

- The SonarQube Cloud project is now `asus-zenbook-linux-tools`, bound to the
  GitHub repository, with automatic analysis disabled so the CI scan — the one
  that carries Python and shell coverage — is the single source of truth.
  `sonar-project.properties` and the README badge follow the new key.

### 📦 Dependency updates bundled with this release

- **`pylint` 4.0.8 → 4.0.9**; every other Python and npm pin was already at its
  latest release, as were the pinned GitHub Actions and Docker base digests.

### 🧪 Verification

- Full unit suite: 792 tests plus 51 subtests pass.
- `scripts/run-lints.sh`: both waves pass (shellcheck, pylint 10.00/10, ruff,
  hadolint, markdownlint, radon rank A, version sync).

## 📦 Installation Quick-Start

### Ubuntu PPA (resolute)

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

### GitHub Release packages (all supported families)

Download assets and **`SHA256SUMS`** from the
[v1.0.8 GitHub Release](https://github.com/ventura8/asus-zenbook-linux-tools/releases/tag/v1.0.8).
Verify the downloaded asset before installation:

```bash
grep -F 'your-asset-filename' SHA256SUMS | sha256sum -c -
```

| Asset | Install (after checksum verify) |
| --- | --- |
| `.deb` | `sudo apt install ./asus-zenbook-linux-tools_*.deb` |
| `.rpm` (Fedora/Rocky/Alma) | `sudo dnf install ./asus-zenbook-linux-tools-*.rpm` |
| `.rpm` (openSUSE) | `sudo zypper install --allow-unsigned-rpm ./asus-zenbook-linux-tools-*.rpm` |
| `.pkg.tar.zst` | `sudo pacman -U ./asus-zenbook-linux-tools-*.pkg.tar.zst` |
| `.AppImage` | `sudo ./asus-zenbook-linux-tools-*-x86_64.AppImage` |
| `.flatpak` | `sudo flatpak install --system ./asus-zenbook-linux-tools-*.flatpak` then |
| | `sudo flatpak run org.github.ventura8.AsusZenBookLinuxTools` |
| `.snap` | `sudo snap install --dangerous ./asus-zenbook-linux-tools_*.snap` (after checksum verify) |

Reconfigure after any native package install: `sudo asus-zenbook-configure`.

### Download install.sh, verify checksum, and run with sudo bash (any supported distro)

```bash
curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.8/install.sh.sha256 \
  -o install.sh.sha256 &&
  curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.8/install.sh \
  -o install.sh &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```

Both files come from the same GitHub release tag; `sha256sum -c` is an integrity
check that the downloaded script matches its checksum file—not independent or
authenticated verification from a separate trusted channel.
