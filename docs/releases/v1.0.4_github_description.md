# ASUS ZenBook Linux Tools v1.0.4 - Multi-Desktop E2E Testing & Package Teardown Hardening

**ASUS ZenBook Linux Tools v1.0.4** brings comprehensive multi-desktop end-to-end test
coverage across GNOME, KDE Plasma, XFCE, LXQt, Cinnamon, and MATE, alongside hardened
package teardown and exit-code propagation in Debian package hooks.

---

## 🖥️ Multi-desktop E2E test verification

* **Comprehensive DE coverage**: End-to-end integration tests for GNOME, KDE Plasma,
  XFCE, LXQt, Cinnamon, and MATE.
* **Control center & settings**: Verified native settings manager launching and D-Bus
  activation across all 6 desktop families.
* **Display modes & shortcuts**: Tested fallback display tools and keybinding writes
  (`kwriteconfig6`, `xfconf-query`, `gsettings`).
* **Screenshot tools**: Validated screenshot triggers via D-Bus (`ShowScreenshotUI`)
  and native binaries (`spectacle`, `xfce4-screenshooter`, `mate-screenshot`).
* **Shortcut backup & restoration**: Verified full keybinding backup and restore cycles
  during uninstallation across all desktop environments.

## 🛡️ Packaging & teardown hardening

* **Prerm exit-status preservation**: Hardened [`debian/prerm`](../../debian/prerm)
  to preserve `uninstall.sh` return status while ensuring full bytecode cache cleanup.
* **Bytecode teardown**: Guaranteed share `__pycache__` removal on package removal/purge.

## 🧪 Quality gates & test infrastructure

* **Isolated daemon E2E tests**: Split multi-DE tests into single-subprocess invocations
  with bounded 20–30 second execution timeouts.
* **Nine distro lanes verified**: Validated against Ubuntu 26.04, Debian trixie,
  Fedora 44, Rocky 10, AlmaLinux 10, openSUSE Tumbleweed, openSUSE Leap 16.0,
  Arch Linux, and Manjaro base.
* **High code coverage**: Maintained $\ge 90\%$ code coverage across product shell
  and Python daemons (96% total Python coverage).

## 📥 Installation

### Ubuntu PPA (resolute)

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

### GitHub Release packages

Download **`SHA256SUMS`** and your release asset from the
[v1.0.4 release assets](https://github.com/ventura8/asus-zenbook-linux-tools/releases/tag/v1.0.4),
then verify the downloaded asset before install:

```bash
grep -F 'your-asset-filename' SHA256SUMS | sha256sum -c -
```

| Asset | Install (after checksum verify) |
| --- | --- |
| `.deb` | `sudo apt install ./asus-zenbook-linux-tools_*.deb` |
| `.rpm` (Fedora/Rocky/Alma) | `sudo dnf install ./asus-zenbook-linux-tools-*.rpm` |
| `.rpm` (openSUSE) | `sudo zypper install --allow-unsigned-rpm ./asus-zenbook-linux-tools-*.rpm` |
| `.pkg.tar.zst` | `sudo pacman -U ./asus-zenbook-linux-tools-*.pkg.tar.zst` |
| `.AppImage` | `sudo ./asus-zenbook-linux-tools-*-x86_64.AppImage` |
| `.flatpak` | `sudo flatpak install --system ./asus-zenbook-linux-tools-*.flatpak` then |
| | `sudo flatpak run org.github.ventura8.AsusZenBookLinuxTools` |
| `.snap` | `sudo snap install --dangerous ./asus-zenbook-linux-tools_*.snap` (after checksum verify) |

Portable AppImage / Flatpak / Snap installer bundles are also attached; native
packages are recommended for systemd and udev integration.

### Download install.sh and verify integrity (any supported distro)

Both files come from the same GitHub release tag; `sha256sum -c` is an integrity
check that the downloaded script matches its checksum file—not independent or
authenticated verification from a separate trusted channel.

```bash
curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.4/install.sh.sha256 \
  -o install.sh.sha256 &&
  curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.4/install.sh \
  -o install.sh &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```
