# ASUS ZenBook Linux Tools v1.0.1 - Dynamic Install Progress & Empty Selection

Installer progress now matches the work that will actually run, empty component
selection is a successful no-op, and desktop configure progress is localized for
GNOME, KDE Plasma, LXQt, Cinnamon, and MATE (XFCE stays English).

---

## 📊 Dynamic `[n/m]` progress

* `Choose components` prints **without** a fraction (total is unknown until after
  the wizard).
* Remaining work is deps (when package install is not skipped) + scripts/services +
  optional DESKTOP configure.
* `SKIP_PKG_INSTALL=1`: WMI only is `[1/1]`; WMI + DESKTOP is `[1/2]` then `[2/2]`.

## ☑️ Empty selection is a successful no-op

* TUI Ok with nothing checked, `NONINTERACTIVE_CHOICE=` / `none`, or text `,` install
  nothing and exit 0 (`No components were selected. Nothing was installed.`).
* **Esc / Cancel** still abort. Text-mode **Enter** and no-TTY default still mean all
  recommended components.

## 🖥️ Desktop compatibility

DESKTOP shortcuts remain **GNOME, KDE Plasma, XFCE, LXQt, Cinnamon, and MATE**.
CI lanes remain Ubuntu 26.04, Debian trixie, Fedora 44, Rocky 10, openSUSE
Tumbleweed, Arch latest, openSUSE Leap 16.0, AlmaLinux 10, and Manjaro base.

## 🌐 Gettext & packaging

* Cheap-wave `msgfmt -c` PO lint on all catalogs; DE progress / `none` strings filled
  across Whisper-aligned languages.
* Deb smoke cleans leftover package `.deb` globs; kcov `install_none` covers the
  empty-selection completion path.
* Arch/Manjaro CI images retry `pacman -Syu`/`-S` on rolling-mirror 404s; Arch
  pins non-geo mirrors. Rocky/Alma kcov installs `libcurl-devel` at the
  installed libcurl NEVRA (`el10-kcov-libcurl.sh`).

## 🧪 Tests

All 16 WMI / TOUCHPAD / SOUND / DESKTOP subsets in
`tests/unit/shell/test_install_component_matrix.py`, plus TUI uncheck-all, mock e2e
no-op, and kcov empty-install coverage.

## 📥 Installation

### Ubuntu PPA (resolute)

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

### Checksum-verified installer (any supported distro)

```bash
curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.1/install.sh.sha256 \
  -o install.sh.sha256 &&
  curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.1/install.sh \
  -o install.sh &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```
