# ASUS ZenBook Linux Tools v1.0.9 - SonarQube Cleanup, Hardware-Validated

**ASUS ZenBook Linux Tools v1.0.9** clears the 1,795 SonarQube Cloud
maintainability findings in the shell code base without changing behaviour, and
fixes four defects found while validating that on a ZenBook Pro Duo (UX582HS).

---

## 🧹 SonarQube shell cleanup

* `[[ … ]]` tests, explicit returns, `*) ;;` default arms, named locals for
  positional parameters, and hoisted constants across product, installer,
  packaging and CI shell. No gettext msgids changed.
* Helper extractions keep every function at CCN ≤ 5; file splits keep every file
  under 600 lines.
* Arithmetic operands read from env, files, sysfs or command output are
  digits-checked before any `[[ -eq ]]`-style comparison.

## 🐛 Fixes found during hardware validation

* **Zero-padded values** (`08`, `0150`) are read as decimal again in the install
  command timeout clamps, the test-mode root check and the fan profile value.
* **Esc / Cancel** in the installer's component checklist now aborts the install
  instead of dropping into the text prompt.
* **Real-system E2E** (`scripts/run_real_e2e.sh`) can discover its tests again.
* kcov coverage kept at ≥90% on `lib/asus-common.sh` and `lib/install-mate.sh`.

## ✅ Verification

* `./scripts/build-and-test.sh --full` green locally (lint waves, deb and
  release package smoke, kcov/python ≥90% merge, all three compat families);
  CI green (76 jobs); SonarQube PR quality gate passed with 0 new issues.
* Real install/uninstall E2E and a full hardware checklist on the UX582HS: fan,
  camera, ScreenPad toggle and brightness OSD, Display Toggle, window swap,
  touchpad Share, sound after suspend/resume, MyASUS, and a clean uninstall.

## 📥 Installation

### Ubuntu PPA (resolute)

```bash
sudo add-apt-repository ppa:ventura8/asus-zenbook-linux-tools &&
  sudo apt update &&
  sudo apt install asus-zenbook-linux-tools
```

### GitHub Release packages

Download **`SHA256SUMS`** and your release asset from the
[v1.0.9 release assets](https://github.com/ventura8/asus-zenbook-linux-tools/releases/tag/v1.0.9),
then verify the downloaded asset before install:

```bash
grep -F 'your-asset-filename' SHA256SUMS | sha256sum -c -
```

| Asset | Install (after checksum verify) |
| --- | --- |
| `.deb` | `sudo apt install ./asus-zenbook-linux-tools_*.deb` |
| `.rpm` (Fedora/Rocky/Alma) | `sudo dnf install ./asus-zenbook-linux-tools-*.rpm` |
| `.rpm` (openSUSE) | `sudo zypper install --allow-unsigned-rpm ./asus-zenbook-linux-tools-*.rpm` |
| `.pkg.tar.zst` | `sudo pacman -U ./asus-zenbook-linux-tools-*.pkg.tar.zst` |
| `.AppImage` | `sudo ./asus-zenbook-linux-tools-*-x86_64.AppImage` |
| `.flatpak` | `sudo flatpak install --system ./asus-zenbook-linux-tools-*.flatpak` then |
| | `sudo flatpak run org.github.ventura8.AsusZenBookLinuxTools` |
| `.snap` | `sudo snap install --dangerous ./asus-zenbook-linux-tools_*.snap` (after checksum verify) |

Portable AppImage / Flatpak / Snap installer bundles are also attached; native
packages are recommended for systemd and udev integration.

### Download install.sh and verify integrity (any supported distro)

Both files come from the same GitHub release tag; `sha256sum -c` is an integrity
check that the downloaded script matches its checksum file—not independent or
authenticated verification from a separate trusted channel.

```bash
curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.9/install.sh.sha256 \
  -o install.sh.sha256 &&
  curl -fsSL \
  https://raw.githubusercontent.com/ventura8/asus-zenbook-linux-tools/v1.0.9/install.sh \
  -o install.sh &&
  sha256sum -c install.sh.sha256 &&
  sudo bash ./install.sh
```
